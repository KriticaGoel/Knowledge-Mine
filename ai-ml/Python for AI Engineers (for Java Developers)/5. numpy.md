4. Array Operations
    * Array indexing and slicing
      * 1D array indexing
      ```
      sales = np.array([100, 200, 300, 400, 500, 600])
          print(sales[0]) 
          print(sales[1:4])
          print(sales[:3])
          print(sales[::2])
          print(sales[-3:])
          print(sales[[0, 2, 5]])
      ```
      * 2D array indexing
      ```
      sales = np.array([[100, 200, 300], [400, 500, 600]])```
          print(sales[0, 1]) 
          print(sales[1, :])
          print(sales[:, 2])
          print(sales[::2, ::2])
      ```
      * 3D array indexing
      ```
      sales = np.array([[[100, 200], [300, 400]], [[500, 600], [700, 800]]])
          print(sales[0, 1, 1])
          print(sales[1, :, :])
          print(sales[:, 1, :])
          print(sales[:, :, 1])
      ```
      * Boolean Indexing
      ```
      sales = np.array([100, 200, 300, 400, 500, 600])
      result = sales[sales > 300]
      print(result)
      ```

```
import numpy as np

sales = np.array([100, 200, 300, 400])

print("Shape:", sales.shape)
print("Dimensions:", sales.ndim)
print("Data type:", sales.dtype)
print("Item size:", sales.itemsize)
print("Total buffer size:", sales.nbytes)
print("Strides:", sales.strides)
print("Owns data:", sales.flags.owndata)

matrix = sales.reshape(2, 2)

print("\nAfter reshape:")
print("Shape:", matrix.shape)
print("Owns data:", matrix.flags.owndata)
print("Shares memory:", np.shares_memory(sales, matrix))
