2. NumPy Fundamentals
    * Create Array 1D from list -np.array([1,2,3,4,5])
    * Create Array 2D from list - np.array([[1,2,3],[4,5,6]])
    * Create Array 3D from list - np.array([[[1,2],[3,4]],[[5,6],[7,8]]])
    * Create Array 1D from tuple - np.array((1,2,3,4,5))
    * Create Array 2D from tuple - np.array(((1,2,3),(4,5,6)))
    * Create Array 3D from tuple - np.array((((1,2),(3,4)),((5,6),(7,8))))
    * Create Array 1D from range - np.array( range(1,7)) / np.arange(1,7)
    * Create Array 2D from range - np.arange(1,13).reshape(3,4)/ np.arange(range(1,13)).reshape(3,-1)
    * Create Array 3D from range - np.arange(1,9).reshape(2,2,2) /np.arange(1,9).reshape(2,2,-1)
    * Create 3*4 matrix with random values
      * np.random.rand(3,4) - random values in [0, 1] #1D
      * np.random.randint(1,10,(3,4)) - random values in [1, 10] #2D
      * np.random.randint(1,20,(3,4,5),dtype=np.int64) - random values in [1, 20] #3D
      * np.arange(1,11).reshape(2,-1) # -1 tell numpy to auto calculate columns based on rows
    * Create 3*4 matrix with zeros - np.zeros((3,4))
    * Create 3*4 matrix with ones -np.ones((2,5,2))
    * identity square matrix - np.identity(3) # always k=0
    * identity square or rectangular matrix - np.eye(2,4,k=2) # k=0 main diagonal, k>0 upper diagonal, k<0 lower diagonal
    * matrix filled with 7 - np.full((2,3),7)
    * matrix filled with even number - np.arange(2,20,2).reshape(3,-1)
    * matrix filled with evenly spaced -np.linspace(start, stop, num=50) #num-How many numbers you want in total. Default is 50. Stop included
3. Array attributes
    * Find Dimensions of array - a.shape - returns a tuple of array dimensions
    * Total number of elements in array - a.size - returns total number of elements in array
    * Data type of elements in array - a.dtype - returns data type of elements in array
    * Bytes per element in array - a.itemsize - returns size of each element in bytes
    * Total number of bytes in the array - a.nbytes - returns total number of bytes in the array
    * strides - a.strides - returns tuple of bytes to step in each dimension
    * Type Conversion - a.astype(np.float64) - returns a new array with the specified data type
    * Number of dimensions of array - a.ndim - returns number of dimensions of array
   ```
    arr = np.array([1, 2, 3.5, 4, 5])
    arr.dtype
    a=arr.astype(int)
    print(a.dtype)
   ```
    * Strides tell NumPy how many bytes it needs to move in each dimension to access the next element.
4. Array Operations
    * Array indexing and slicing
        * 1D array indexing
      ``` 
      sales = np.array([100, 200, 300, 400, 500, 600])
      print(sales[0]) #100
      print(sales[1:4]) #200 300 400
      print(sales[:3]) #100 200 300
      print(sales[::2]) #100 300 500
      print(sales[-3:]) #400 500 600
      ```

        * 2D array indexing
        * 3D array indexing

   * Array filtering
       * np.where() - np.where(condition, value_if_true, value_if_false)
   * Array reshaping np.reshape() - np.reshape(array, new_shape)
   * Array flattening np.flatten() - np.flatten(array) - convert array to 1D
   * print(m.flatten()) # Always returns 1D copy: [1,2,3,4,5,6]
   * m = np.array([[1,2,3],[4,5,6]])
   * print(m.T) # Transpose: (2,3) → (3,2)
   * print(m.ravel()) # 1D view (no copy if possible)
   * Array broadcasting - NumPy automatically expanding a smaller array's values to perform operations against a larger array, without you manually writing loops or repeating values. Equal OR One is 1
   ```
    A = np.ones((3, 4))
    B = np.ones((4,))
    C = np.ones((3, 1))
    D = np.ones((2, 4))
   
    print(A + B)  # Broadcasting B to match A's shape
        # A=3,4 and B=1,4 =>R =4,4 and L=3,1  
    print(A + C)  # Broadcasting C to match A's shape
        # A=3,4 and C=3,1 =>R =4,1 and L=3,3
    print(A + D)  # ValueError
        # A=3,4 and D=2,4 =>R =4,4 and L=3,2
    print(B + D)  # Broadcasting D to match A's shape
        # B=1,4 and D=2,4 =>R =4,4 and L=1,2
    print(B + C)  # Broadcasting D to match A's shape
        # B=1,4 and C=3,1 =>R =4,1 and L=1,3
   ```
5. Mathematical Operations
    * Element-wise Arithmetic
 
   ```
   a = np.array([1, 2, 3, 4])
   b = np.array([10, 20, 30, 40])
   print(a + b) # [11, 22, 33, 44]
   print(b - a) # [9, 18, 27, 36]
   print(a * b) # [10, 40, 90, 160]
   print(b / a) # [10., 10., 10., 10.]
   print(a ** 2) # [1, 4, 9, 16]
   # Scalar operations (broadcasting with scalar)
   print(a * 5) # [5, 10, 15, 20]
   print(a + 100) # [101, 102, 103, 104]
    
   ```
    * Universal Functions (ufuncs) - ufuncs are optimised C-level functions that operate element-wise on arrays — much faster than Python
      loops:
        * Square root of each element - np.sqrt(a)
        * Absolute value - np.abs(a)
        * Exponential of each element - e^x for each element - np.exp(a)
        * Logarithm of each element - log(x) for each element - np.log(x)
        * Trigonometric functions - sin, cos, tan - np.sin/cos/tan(a)
        * Log base 2 - np.log2(a)
        * Log base 10 - np.log10(a)
        * Round down / round up - np.floor(a) / np.ceil(a)
        * Round to n decimal places - np.round(a, decimals=n)
    *  Matrix multiplication
      * Element-wise multiply
        ```
        A = np.array([[1,2],[3,4]])
        B = np.array([[5,6],[7,8]])
        # Element-wise multiply (NOT matrix multiply)
        print(A * B) # [[5,12],[21,32]]
        ```        
      * Matrix multiplication
          * using np.dot() - print(np.dot(A, B)) # same as @
          * @ operator - print(A @ B) # [[19,22],[43,50]]
          * using np.matmul()  -  print(np.matmul(A, B)) # same as @
      * Matrix inverse & determinant
          * inverse of A  -  print(np.linalg.inv(A))
          * determinant: -2.0  -  print(np.linalg.det(A))
    * Aggregations and Statistics
        * Sum of all elements - np.sum(a)
        * Minimum / Maximum value -np.min(a) / np.max(a)
        * Index of min / max - np.argmin(a) / np.argmax(a)
        * Arithmetic mean - np.mean(a)
        * Median value - np.median(a)
        * Standard deviation - np.std(a)
        * Variance - np.var(a)
        * Cumulative sum - np.cumsum(a)
        * q-th percentile - np.percentile(a, q)
        * Unique elements (sorted) - np.unique(a)
        * Product of all values - np.prod(a)
        * Count of non-zero values - np.count_nonzero(a)
        * total sales for each row -np.sum(sales, axis=1)
        * total sales for each column -np.sum(sales, axis=0)
    * vectorization
