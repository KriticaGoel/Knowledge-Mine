## Pandas introduction
Pandas allows you to:
- Read Excel and CSV files.
- Filter records.
- Calculate business metrics.
- Handle missing data.
- Join multiple datasets.
- Clean inconsistent data.
- Prepare datasets for reporting and machine learning.

### Two fundamental data structures
#### Series 
 A Series is a one-dimensional labeled array.
```python
import pandas as pd

revenue = pd.Series([1000, 2000, 3000])

print(revenue)
```
```output
0    1000
1    2000
2    3000
dtype: int64
```
#### DataFrame 
  
 A DataFrame is a two-dimensional labeled data structure containing rows and columns.
```python
import pandas as pd

data = {
    "product": ["Laptop", "Mouse", "Keyboard"],
    "price": [50000, 500, 1500],
    "quantity": [2, 5, 3]
}

df = pd.DataFrame(data)

print(df) 
```
```output
    product   price   quantity
0   Laptop    50000       2
1    Mouse    500         5
2  Keyboard   1500        3
```

#### Index 
  
An Index is a label that uniquely identifies each row in a DataFrame. It can be thought of as the row labels of the DataFrame. By default, Pandas assigns an integer index starting from 0 to each row. However, you can also set a custom index using one of the columns in the DataFrame.
```python
df = pd.DataFrame(
    {
        "employee": ["Amit", "Rahul", "Priya"],
        "salary": [50000, 60000, 70000]
    },
    index=["E001", "E002", "E003"]
)
```

```output
Index    employee  salary
E001      Amit    50000
E002     Rahul   60000
E003     Priya   70000
```

print(df.index) / print(df.columns)
```output
Index(['E001', 'E002', 'E003'], dtype='object')
Index(['employee', 'salary'], dtype='object')
```


## DataFrame Creation
1. Dictionary
```python
import pandas as pd

data = {
    "employee": ["Amit", "Rahul", "Priya"],
    "salary": [50000, 60000, 70000],
    "department": ["IT", "HR", "Finance"]
}

df = pd.DataFrame(data)

print(df) 
```
```output
employee  salary department
0      Amit   50000         IT
1     Rahul   60000         HR
2     Priya   70000    Finance
```
2. List of dictionaries
```python
data = [
    {"employee": "Amit", "salary": 50000},
    {"employee": "Rahul", "salary": 60000},
    {"employee": "Priya", "salary": 70000}
]

df = pd.DataFrame(data) 
```

```output
Index   employee  salary 
0         Amit    50000         
1         Rahul   60000         
2         Priya   70000  
```
3. List of lists
```python
data = [
    ["Amit", 50000, "IT"],
    ["Rahul", 60000, "HR"],
    ["Priya", 70000, "Finance"]
]

df = pd.DataFrame(
    data,
    columns=["employee", "salary", "department"]
) 
```
```output
Index   employee  salary department
0         Amit    50000         IT
1         Rahul   60000         HR
2         Priya   70000    Finance
```
4. NumPy arrays
```python
import numpy as np
import pandas as pd

data = np.array([
    ["Amit", 50000],
    ["Rahul", 60000],
    ["Priya", 70000]
])

df = pd.DataFrame(
    data,
    columns=["employee", "salary"]
) 
```

```output
Index   employee  salary
0         Amit    50000
1         Rahul   60000
2         Priya   70000
```

5. External files (CSV and Excel)
```python
import pandas as pd

df = pd.read_csv("data.csv")

df = pd.read_excel("transactions.xlsx")

df = pd.read_json("transactions.json")
```

6. Insert row in dataframe
```
new_row = {'employee': 'Kritica', 'salary': 90000}

```


## DataFrame Inspection and Exploration

1. head() - Returns the first n rows of the DataFrame (default is 5).
2. tail() - Returns the last n rows of the DataFrame (default is 5).
3. info() - Provides a concise summary of the DataFrame, including the number of non-null entries, data types, and memory usage.
4. describe() - Generates descriptive statistics of the DataFrame, including count, mean, standard deviation, minimum, maximum, and quartiles for numeric columns.
5. head(2) - Returns the first 2 rows of the DataFrame.
6. tail(2) - Returns the last 2 rows of the DataFrame.
7. shape[0] - return total rows of dataframe
8. shape[1] - return total column of dataframe
