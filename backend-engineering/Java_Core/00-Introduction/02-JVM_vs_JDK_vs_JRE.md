JDK

For developing Java applications.

Contains:

* Compiler
* Debugger
* JRE
* Build tools
* 
JRE

For running Java applications.

Contains:

* JVM
* Core Java Libraries

JVM

Responsible for:

* Loading classes
* Managing memory
* Executing bytecode
* Garbage Collection
* Thread management
* Exception handling
* Converting bytecode to machine code
