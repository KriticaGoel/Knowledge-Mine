
## Loading

Suppose you have:
```
public class Student {
    static int count = 10;
}
```

When you execute:
```
Student s = new Student();
```
The JVM first checks:

> "Is Student.class already loaded?"

If not:

The ClassLoader:

* Finds Student.class
* Reads the bytecode
* Creates the **Class object**
* Stores class metadata in **Metaspace**

After Loading:
```
Metaspace

Student.class Metadata

Class Name
Methods
Fields
Constructors
Bytecode
Runtime Constant Pool
```

Important

At this stage:

❌ Static variables are not initialized.

❌ Static blocks are not executed.

Only the class metadata is loaded.


### First time loading of class

*  new instance is created
*  Invoking static method
*  Accessing static field
   *  Exception - Compile-time constants
* Subclass is loaded
* Run from command line
* Reflection

### First time loading of interface
*  Invoking static method
*  Accessing static field
   *  Exception - Compile-time constants
* Subclass or sub interface is loaded
* Run from command line
* Reflection

### Class Objects

All the objects that we create from a  particular class is always done using the class object of the class.

Class objects created for Class, Interface, Primitives, Void, Arrays

Class objects contains meta-information of the class.
1. String getName();
2. Class getSuperClass();
3. boolean isInterface();
4. Class[] getInterface();
5. ClassLoader getClassLoader();
