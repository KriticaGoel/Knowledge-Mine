## Verification

The JVM checks whether the bytecode is valid and safe.

Examples:

* Is the bytecode structurally correct?
* Are method calls valid?
* Has the .class file been corrupted?
* Is it trying to break JVM rules?

This is one reason Java is considered secure.


## Preparation

Now the JVM allocates memory for static variables and assigns them default values.

Example:
```
class Demo {

    static int x = 100;

}
```
During Preparation:
```
x = 0
```
Wait... not 100?

Exactly.

Only the default value is assigned initially.

Actual initialization comes later.

## Initialization

Now Java executes:
```
static int x = 100;
```
So:

Before Initialization
```
x = 0

↓

Initialization

x = 100
```
This phase also executes:
```
static {

    System.out.println("Static Block");

}
```
That's why static blocks run before main().
```
class Demo {

    static int x = 100;

    static {

        System.out.println("Static");

    }

}
```
