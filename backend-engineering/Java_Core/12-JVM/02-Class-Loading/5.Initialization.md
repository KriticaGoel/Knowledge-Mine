```
class Test {

    static int x = getValue();

    static {
        System.out.println("Static Block");
    }

    static int getValue() {
        System.out.println("getValue()");
        return 10;
    }

    public static void main(String[] args) {
        System.out.println(x);
    }
}

```

JVM Execution

1. Application ClassLoader

Loads Test.class.

2. Linking
   
2.1. Verification

Checks whether the bytecode is valid.

2.2 Preparation

Memory is allocated for static variables.

x = 0

3. Initialization

## Practice 2:

```
class Test {

    static {
        System.out.println(x);
    }

    static int x = 10;

    public static void main(String[] args) {
    }
}
```
Compile time Exception since x declaration is after the static block. The JVM does not know about x when it tries to print it in the static block.
