### Step 6: main() ends
The JVM removes the main() stack frame.

```
        STACK
    ----------------
    null
    ----------------
    
        
        HEAP
    --------------
    Person Object
    age = 25
    name = "John"
    --------------

```
The local variables (x and p) disappear because the method has finished.

Now the Person object in the Heap has no references pointing to it.

It becomes eligible for garbage collection.

### Why doesn't JVM remove it immediately?

Every time a method returns, the JVM would need to:

search the heap
check references
free memory

That would make Java much slower.

Instead, Java says:

"I'll clean many unreachable objects together later."

This is why Java has a Garbage Collector (GC).

System.gc() is only a request (hint) to the JVM to perform garbage collection. The JVM is free to ignore it or run GC later. Therefore, you cannot guarantee exactly when the object will be collected.


x and p are independent reference variables.

## Next Challenge

```
class Person {
    int age;
}

public class Main {

    public static void main(String[] args) {

        Person p = new Person();

        greet(p);

        System.out.println(p.age);

    }

    static void greet(Person x) {

        x = new Person();

        x.age = 100;

    }
}
```


Step 1:  Person p = new Person();

```
Stack
main()

p refer to Person Object 1

Heap
Person Object 1
age = 0
```

Step 2: greet(p);

A new stack frame is created.

Whatever value in p (reference/address) is copied to x. So x also points to Person Object 1.


```
Stack
greet() Frame
x refer to Person Object 1  

main() Frame
p refer to Person Object 1
```

x and p are different variables.

They just happen to store the same reference value.

This is why Java is called pass-by-value.


Step 3 : x= new Person();

```
Stack
greet() Frame
x refer to Person Object 2 

main() Frame
p refer to Person Object 1


Heap
Person Object 1
age = 0

Person Object 2
age=0

```


Step 4: x.age=25

```
Stack
greet() Frame
x refer to Person Object 2 

main() Frame
p refer to Person Object 1


Heap
Person Object 1
age = 0

Person Object 2
age=25

```

Step 5: greet() finishes.

```
Stack

main() Frame
p refer to Person Object 1


Heap
Person Object 1
age = 0

Person Object 2
age=25
```

Person object 2 is eligible for Garbage Collection

Step 6 : System.out.println(p.age);

Output is 0 since p still points to object 1
