What happen when we run Java Hello

```
java Main

↓

Operating System starts process

↓

JVM starts

↓

Class Loader loads Main.class

↓

main() method found

↓

main() pushed onto stack

↓

Execution begins

↓

Objects created in heap

↓

Methods use stack frames

↓

Program ends

↓

Memory cleaned up

↓

Process exits
```
