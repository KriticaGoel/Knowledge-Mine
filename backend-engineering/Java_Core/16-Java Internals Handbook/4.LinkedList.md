>LinkedList was created for node-based sequential/deque-style operations where inserting/removing at known positions or ends matters more than random access and memory efficiency.
 

## Why was LinkedList created?
In Arraylist removing from the start/middle costs O(n)

However, in linked list that is O(1) if you have the reference to the node.


ArrayList = contiguous backing array

LinkedList = chain of nodes

## Internal Data Structure

Java's LinkedList is a doubly linked list.

Each node contains:
```
Node
├── item
├── next
└── prev
```
Conceptually:
```
       prev       next
        ↓          ↓
     ┌──────┬──────┬──────┐
     │ prev │ item │ next │
     └──────┴──────┴──────┘
```
For example:
```
LinkedList<Integer> list = new LinkedList<>();

list.add(10);
list.add(20);
list.add(30);
```
Memory structure:
```
first                                      last
↓                                          ↓
┌────┬────┬────┐    ┌────┬────┬────┐    ┌────┬────┬────┐
│null│ 10 │  → │───→│ ←  │ 20 │  → │───→│ ←  │ 30 │null│
└────┴────┴────┘    └────┴────┴────┘    └────┴────┴────┘
```
Notice:

Node 10
```
prev = null
item = 10
next = Node20
```
Node 20
```
prev = Node10
item = 20
next = Node30
```
Node 30
```
prev = Node20
item = 30
next = null
```

## Source Code Walkthrough

```
public class LinkedList<E> {

    transient int size = 0;

    transient Node<E> first;

    transient Node<E> last;

    private static class Node<E> {

        E item;

        Node<E> next;

        Node<E> prev;

        Node(Node<E> prev, E element, Node<E> next) {
            this.item = element;
            this.next = next;
            this.prev = prev;
        }
    }
}
```
```
LinkedList
    |
    ├── first
    ├── last
    └── size

Node
    |
    ├── prev
    ├── item
    └── next
```

### add(E e)

```
public boolean add(E e) {
    linkLast(e);
    return true;
}
```

```
void linkLast(E e) {

    Node<E> l = last;

    Node<E> newNode =
        new Node<>(l, e, null);

    last = newNode;

    if (l == null)
        first = newNode;
    else
        l.next = newNode;

    size++;
}
```

## Time Complexity

| Operation       | LinkedList |
| --------------- | ---------: |
| `add()` at end  |   **O(1)** |
| `addFirst()`    |   **O(1)** |
| `addLast()`     |   **O(1)** |
| `removeFirst()` |   **O(1)** |
| `removeLast()`  |   **O(1)** |
| `get(index)`    |   **O(n)** |
| `set(index)`    |   **O(n)** |
| `contains()`    |   **O(n)** |
| `indexOf()`     |   **O(n)** |
| `remove(index)` |   **O(n)** |

LinkedList insertion/removal is O(1) only when the node/position is already known else its O(n) since we need to traverse to the node before performing the operation.

## Thread Safety
LinkedList is not thread-safe.

If multiple threads modify it concurrently:
```
LinkedList<Integer> list = new LinkedList<>();
```
there is no automatic synchronization.

If synchronization is required, you can use mechanisms such as:
```
Collections.synchronizedList(...)
```

Linkedlist implements 
* List
* Deque
* Queue

## Linkedlist from scratch

```
class MyLinkedList<E> {

    private Node<E> head;
    private Node<E> tail;
    private int size;

    static class Node<E> {
        E data;
        Node<E> next;
        Node<E> prev;

        Node(Node<E> prev, E data, Node<E> next) {
            this.prev = prev;
            this.data = data;
            this.next = next;
        }
    }

    public void add(E data) {

        Node<E> newNode =
                new Node<>(tail, data, null);

        if (tail == null) {
            head = newNode;
        } else {
            tail.next = newNode;
        }

        tail = newNode;
        size++;
    }
}
```
