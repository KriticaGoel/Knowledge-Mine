> FIFO — First In, First Out

Queue is an interface, not a concrete data structure.

Common implementations of Queue include:
```
Queue
├── LinkedList - Normal FIFO possible - Queue<Integer> q = new LinkedList<>();
├── PriorityQueue - Highest/lowest priority comes first - Queue<Integer> q = new PriorityQueue<>();
└── ArrayDeque - Efficient double-ended queue  - Queue<Integer> q = new ArrayDeque<>();
```
## Part 1 — LinkedList
```
Queue<Integer> q = new LinkedList<>();

q.add(10);
q.add(20);
q.add(30);
```

Methods:
```
| Operation | Throws exception | Special value |
| --------- | ---------------- | ------------- |
| Insert    | `add()`          | `offer()` If empty returns false    |
| Remove    | `remove()`  NoSuchElementException     | `poll()` head If empty returns null      |
| Examine   | `element()` NoSuchElementException     | `peek()` head  If empty returns null    |

```
